# TCDS

TCDS est un système léger destiné aux terminaux NComputing RX300.

Le projet vise à fournir un environnement indépendant des logiciels
propriétaires ou abandonnés utilisés dans les anciennes versions du projet.

## Objectifs

- Fonctionner sur NComputing RX300.
- Utiliser une base Linux/PiOS compatible avec le matériel.
- Fournir un environnement minimal et rapide.
- Centraliser la configuration du terminal.
- Permettre la connexion aux services du réseau.
- Être construit et maintenu à partir d'une VM Linux.
- Produire une image SD déployable sur les RX300.

## Architecture

Le développement est réalisé dans une VM Debian.

Les images destinées aux RX300 sont produites depuis cette VM.

## État du projet

Développement initial.
